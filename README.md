# NetHome Manager

Sistema de gestión para empresa de internet residencial.

## Descripción

NetHome Manager es una plataforma web diseñada para administrar clientes, planes, pagos, instalaciones y tickets de soporte en una empresa de servicio de internet residencial.

## Problema que resuelve

Muchas empresas pequeñas gestionan sus operaciones en Excel o papel, generando errores en facturación, falta de seguimiento en soporte y mala organización.
